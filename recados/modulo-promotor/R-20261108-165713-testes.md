# CI 2º retrato: sync-cadastros.db.test.ts exige linha do provedor legado concorrente (página vazia pela ADR 0034)

## Contexto
2º retrato do CI (commit 83b2a89, branch `verificacao/retrato-2026-11-08-1600`, ci.yml run 42520547448). `modules/promotor/api/sync-cadastros.db.test.ts` cai em "cada provedor devolve as linhas do tenant A no formato estrito do contrato":

```
AssertionError: concorrente: expected 0 to be greater than 0
 ❯ api/sync-cadastros.db.test.ts:70  expect(linhas.length, p.entidade.nome).toBeGreaterThan(0)
```

Causa (teste desatualizado pela T-0113/ADR 0034, a produção está certa): a entidade legada `concorrente` agora devolve página vazia de propósito (o caso "ADR 0034: a entidade legada `concorrente` devolve página vazia" do MESMO arquivo passa). O laço da linha 68 percorre todos os `provedoresPullCadastros`, inclusive o `concorrente`, e exige pelo menos 1 linha.

## O que preciso
Prioridade alta. No laço da linha 68, pular o provedor `concorrente` (ou exigir `> 0` só para os demais e `toEqual([])` para ele), citando a ADR 0034.

## Pronto quando
`modules/promotor/api/sync-cadastros.db.test.ts` verde no CI.
