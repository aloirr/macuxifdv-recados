# Campo: pedir todas as permissões ao abrir; a tela "Permissões" só para o que foi negado; sai "Como usamos a localização"

## Mensagem do dono do produto (chat com o Agente PO, 20/11/2026 ~05h25 de Manaus), com o print da tela "Permissões" do Macuxi Campo v1.0.16
> "Quando o app abrir, já deve ser solicitado todas as permissões, sem precisar ir para essa tela. Caso o usuário negue alguma, aí sim vai para essa tela apenas com o item que falta. Tire aquela frase "como usamos a localização" dessa tela"

Print: `recados/anexos/R-20261120-campo-permissoes.jpg`. Mostra Notificações, Localização o tempo todo e Câmera com "Falta", Fotos e galeria com "Permitida", o link "Como usamos a localização" e o botão "Permitir".

## O que fica decidido
1. **Ao abrir o app,** ele já pede, direto, todas as permissões que faltam, com as janelas do próprio Android:
   - notificações;
   - localização o tempo todo;
   - câmera;
   - fotos e galeria.

   O usuário **não passa** pela tela "Permissões" antes.
2. **A tela "Permissões" só aparece se o usuário negar alguma,** e mostra **apenas os itens que faltam.** O que já foi permitido não aparece.
3. **Sai o link "Como usamos a localização"** dessa tela.
4. Vale para o Campo e para o Gestão, onde houver a mesma tela.
5. Entra no próximo lote (v1.0.17), com:
   - o parecer do corretor-redundancias;
   - o roteiro do testes no aparelho: primeira abertura, negar uma permissão, voltar ao app e conceder.
