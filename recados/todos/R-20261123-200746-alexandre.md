# Backlog: atualização obrigatória do APK

Alexandre, no chat do Agente PO, em 23/11/2026 20h07 (Manaus):

> Coloque no backlog uma nova tarefa: quando tive um apk novo o app abre com aviso e link para o usuario baixa o novo apk e atualizar. O aviso deve ser: Versão desatualizada, reinstale para continuar. O app so abre com a nova atualização após 24hs de lançamento. Se a atualização for no mesmo dia mandar apenas uma notificação para os usuarios no sininho

## O que fica decidido
- Nova tarefa no BACKLOG, com autorização escrita do Alexandre. Não entra na esteira até ele mandar.
- Vale para os apps Campo e Gestão, quando um APK novo é publicado no link do BKO.
- Nas primeiras 24 h depois do lançamento, os usuários com versão antiga recebem só uma notificação no sininho, com o link do APK novo.
- Passadas 24 h do lançamento, o app com versão antiga abre só com o aviso "Versão desatualizada, reinstale para continuar." e o link para baixar o APK novo. O app só volta a abrir depois de atualizado.
- O gerente cria a tarefa T-nnnn no backlog e define os donos.
