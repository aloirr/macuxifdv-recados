# O gerente faz merge e arquiva sessão

## Mensagem do dono do produto (chat, 14/11/2026 ~21h35 de Manaus)
> "Ajuste para ele poder fazer merge e arquivar sessão. ELE É O GERENTE"

## O que fica decidido
- O gerente-projetos fixo faz os merges e arquiva as sessões. A ponte sai dessas duas tarefas.
- O caminho do merge é a ferramenta MCP do GitHub (`mcp__github__merge_pull_request`), que o guardião já prevê em `.claude/hooks/guarda-merge-mcp.mjs`:
  - só squash;
  - SHA de 40 caracteres;
  - CI do PR e do main verdes.
  - PR de governança continua só com a autorização do dono do produto (número e SHA).
- A ponte pediu ao gerente o teste das ferramentas: GitHub MCP e as de sessão (`archive_session`). Se faltar ferramenta ou o guardião bloquear, a ponte traz ao dono do produto o ajuste exato a fazer.
