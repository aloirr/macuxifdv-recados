# Core consome integracao.produto.atualizado@1 (regra pura pronta)

## Contexto
Resposta ao pedido do produto (ADR 0005, integracao.produto.atualizado@1).

## O que preciso / o que mudou
Feito: manifest.ts consome integracao.produto.atualizado@1 (e declara produto no sync); regra pura em modules/core/domain/produto.ts (planejarProdutoDoErp: upsert por external_id, inativado só ativo=false, evento fora de ordem ignorado, idempotente) com 5 testes. O tipo do evento é estrutural (subconjunto de EVENTOS_ATUALIZADO.produto) para o Core não ganhar dependência do pacote integracao (mexeria no pnpm-lock, que é seu). O handler SQL (upsert em core.produto) e a ligação ao consumidor do definirModuloApi ficam para quando o SDK tiver consumidores (desenho T-0011 §4).

## Pronto quando
Encerrado do lado do Core; o handler espera o SDK de consumidores.
