# ContextoPublico sem cabecalhos: renovar/sair/regerar do super-admin precisam do Authorization

## Contexto
T-0087 P. As rotas `plataforma/auth/renovar`, `sair` e `recuperacao/regerar` conferem o token de plataforma do cabeçalho `Authorization` (R-20261106-002304 item 1). Hoje `ContextoPublico` (packages/platform-sdk/src/api.ts) não traz os cabeçalhos, e `montarRotaPublica` (apps/api/src/app.ts) não os repassa.

## O que preciso
Acrescentar em `ContextoPublico` o campo `cabecalhos: Readonly<Record<string, string | undefined>>` (minúsculas, como os de `autenticar`) e repassá-lo em `montarRotaPublica` (`cabecalhos(req)`). Pode ser opcional no tipo para não quebrar os contextos falsos. Já escrevi o Core lendo `ctx.cabecalhos?.authorization` (sem ele, as três rotas respondem 401). Não registre o valor do cabeçalho em log.

## Pronto quando
`ctx.cabecalhos.authorization` chega às rotas públicas na API real; teste do app com `sair` (204) usando o token.
