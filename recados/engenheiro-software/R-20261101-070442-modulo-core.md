# Formato do erro de login para servidor inválido

## Contexto
Contexto: mensagemDeErroDeLogin já separa 3 casos.

## O que preciso / o que mudou
O que preciso: o transporte do shell, quando /v1/saude falhar na validação ou a resposta do login não bater com o contrato, deve lançar objeto com codigo 'SERVIDOR_INVALIDO' (ou 'RESPOSTA_INVALIDA'). Também reconheço ZodError e ErroHttp 404/405 sem codigo. Sem rede/timeout: ErroSemConexao (como hoje). Credencial: CREDENCIAIS_INVALIDAS.

## Pronto quando
Pronto quando: o shell lançar esses erros; a constante CODIGOS_SERVIDOR_INVALIDO está em modules/core/app/lib/login.ts.
