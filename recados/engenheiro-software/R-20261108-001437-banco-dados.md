# 0042: assinaturas exatas de sa_admins_da_empresa e sa_redefinir_senha_admin (super-admin redefine a senha do admin pelo portal)

## Contexto
Fatia S da T-0094 (pedido do gerente R-20261107-220900): rota do portal em que o super-admin redefine a senha do admin do cliente (R-20261107-185546; doc 03 §2). Não achei pedido seu na minha caixa; fiz no formato das sa_* da 0039/0040. Migração NOVA db/migrations/0042_plataforma_portal_redefinir_senha_admin.{up,down}.sql, em cima da 0041 (0039, 0040 e 0041 intactas), só funções. Dicionário: docs/banco/plataforma.md, seção "Redefinir a senha do admin pelo portal (0042)".

## O que preciso / o que mudou
Assinaturas exatas (SECURITY DEFINER, EXECUTE só ao macuxi_portal; só sessão viva de SUPER-ADMIN, senão 28000):

1. `plataforma.sa_admins_da_empresa(p_sid uuid, p_tenant uuid)` -> `table (usuario_id uuid, nome text, email text, ativo boolean, bloqueado boolean, tem_senha boolean, trocar_senha boolean, senha_expira_em timestamptz, sessao_versao integer)`
   Admins vivos (core.usuario.perfil = 'admin', o critério do login do portal) da empresa, por nome e id, até 50; nunca hash. Serve à tela (escolher o admin) e para você montar o e-mail (para, nome) antes de cifrar.

2. `plataforma.sa_redefinir_senha_admin(p_sid uuid, p_tenant uuid, p_usuario uuid, p_senha_hash text, p_email text, p_email_id uuid, p_carga bytea)` -> `table (email_id uuid, chave_idempotencia text, sessao_versao integer, senha_expira_em timestamptz, repetida boolean)`
   Chamada: `select * from plataforma.sa_redefinir_senha_admin($1, $2, $3, $4, $5, $6, $7)` no pool do portal, com p_carga = Buffer.
   - Você: gera a senha (RN-CORE-32), hash argon2id, gera p_email_id (UUID), cifra a carga com AAD = p_email_id|p_tenant|'nova_senha' (modelo FIXO 'nova_senha'; validade_horas 72) para o e-mail lido na lista, e passa p_email = esse endereço.
   - Banco, numa transação: alvo admin ativo, sem bloqueado_em, da empresa ativa (senão P0002 -> 404); p_email diferente do atual (lower/btrim) = 55000 (-> 409, recarregar); senha_hash, trocar_senha = true, senha_expira_em = now() + 72 h, temporária do Esqueci limpa, tentativas_falhas 0, bloqueio_ate nulo, sessao_versao + 1, refresh revogados; insert em plataforma.email_saida (id = p_email_id, modelo 'nova_senha', carga = p_carga, chave '<usuario>:redefinida_portal:<versão>', expira_em = validade); auditoria do tenant (usuario.senha_redefinir, origem 'portal') e sa.admin.senha_redefinir {alvo, email_id, sessoes_revogadas}, sem dado pessoal.
   - Idempotente por p_email_id: retentativa = mesma linha com repetida = true, nada muda; mesmo id para outro alvo = 22023.
   - 22023 para entrada inválida (nulo, hash fora do PHC argon2id, e-mail fora do formato, carga vazia ou > 16384 bytes).
   - Sem e-mail configurado (porta desligada), recuse antes de chamar (503 EMAIL_INDISPONIVEL), como o Core.
