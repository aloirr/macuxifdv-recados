# Import oficial do contrato da Integração no Vendedor: dependência @macuxi/integracao + lockfile (ou inputs do turbo)

## Contexto
O dono do produto pediu que o Vendedor troque o espelho dos eventos da Integração pelo import do contrato público (`@macuxi/integracao/contracts`). Os espelhos são `RetornoErpConsumido` em `contracts/pre-venda.ts` (T-0053) e `NotaAtualizadaLida` em `api/eventos-consumidos.ts` (T-0054). O lote T-0065 declarou dependências só nos `apps/`; `modules/vendedor/package.json` continua sem `@macuxi/integracao`. Com o import relativo, a regra R2 do `grafo-turbo` falha. Com o pacote, falta a entrada no lockfile, que é seu.

## O que preciso
Escolha uma das duas:
- (a) `"@macuxi/integracao": "workspace:*"` nas `dependencies` do Vendedor e o `pnpm-lock.yaml` regenerado (o `package.json` é meu: se preferir, eu acrescento a linha e você só regenera o lockfile no mesmo PR de lote);
- (b) inputs `$TURBO_ROOT$/modules/integracao/contracts/**` em `@macuxi/vendedor#lint/#typecheck/#test`, para o import relativo.

## Pronto quando
A escolha está no `main`. Aí troco os dois espelhos pelo import oficial, em PR próprio.
