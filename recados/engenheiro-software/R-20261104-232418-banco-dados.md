# 0022_plataforma_geracao_base: coluna geracao_base, girar_geracao_base, giro no --recriar e na restauração

## Contexto
Resposta ao R-20261104-230105 (T-0079; ADR 0021, docs/desenho/T-0079.md). Feito no local, sem commit (lote pelo gerente). Docker do PC desligado: testes de banco escritos, rodam no CI.

## O que foi feito
- **Migração 0022_plataforma_geracao_base** (db/migrations/0022_plataforma_geracao_base.up/down.sql), aditiva e idempotente:
  `alter table plataforma.tenant add column if not exists geracao_base uuid not null default gen_random_uuid();` — tenants existentes ganham um valor cada.
- Função `plataforma.girar_geracao_base(p_tenant uuid default null) returns integer` (null = todos os tenants; devolve quantos girou). SECURITY INVOKER, search_path fixo, `revoke all ... from public`, sem EXECUTE para macuxi_app/macuxi_worker: só o dono do banco (superusuário) gira.
- Leitura: macuxi_app continua só com SELECT em plataforma.tenant pela política isolamento_tenant da 0001 (id = tenant do contexto); nenhum grant novo. Sua consulta `select geracao_base::text from plataforma.tenant where id = $1` dentro do comTenant serve.
- Seed demo `--recriar`: apaga e regrava o tenant (linha nova = valor novo) e ainda chama `girarGeracaoBase(admin, T)` (db/seeds/demo/demo.ts; exportada). Seed sem `--recriar` NÃO gira (upsert não toca a coluna). Primeiro seed de servidor novo: linha nova = valor novo.
- Restauração: db/backup/restaurar-vm.sh roda `select plataforma.girar_geracao_base(null)` no banco restaurado logo depois do pg_restore (antes da contagem e da troca). Backup anterior à 0022: o `banco migrar up` do deploy cria o marcador novo. LEIA-ME do backup atualizado.
- Espelho Drizzle `tenant.geracao_base` (db/esquema/plataforma.ts); dicionário docs/banco/plataforma.md.
- Testes: db/testes/geracao-base.test.ts (estático; app lê só o do próprio tenant, B não vê o de A, sem contexto nada; app sem UPDATE e sem EXECUTE = 42501; update de outras colunas não gira; girar(tenant) só aquele, girar(null) todos; up/down/up idempotente com tenants antigos), db/testes/seed-demo.test.ts (recarga não gira, --recriar gira só o demo), db/testes/backup.test.ts (restaurado tem o mesmo valor da origem; girar(null) troca todos; contagem igual).
