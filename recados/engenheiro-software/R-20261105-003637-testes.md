# D-C1a: scripts/carga/sync-basico.mjs faz login em /v1/core/auth/login (a rota é /v1/auth/login)

## Contexto
A ferramenta chama chamar('/core/auth/login', ...) sobre MACUXI_CARGA_URL=.../v1, mas a rota pública do Core é auth/login, montada em /v1/<caminho> por montarRotaPublica (apps/api/src/app.ts; modules/core/api/index.ts). Contra a API real (local ou demo) sai com 'login falhou (status 404)'. Os testes de carga (tests/carga/sync-basico-t0078.test.ts) usam um repasse de compatibilidade até a correção; o caso 'D-C1a' (it.fails) prova o defeito contra uma API só com /v1/auth/login.

## O que preciso / o que mudou
