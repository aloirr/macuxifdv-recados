# Logout: chamar DELETE /v1/dispositivos/atual/push?dispositivo_id=<uuid> (token de push do aparelho)

## Contexto
Core: token de push passa a ser só do usuário da sessão (PUT remove o mesmo token de outros aparelhos; login de outro usuário no mesmo aparelho troca o dono e zera o token; o POST /v1/auth/logout já limpa o token do aparelho da sessão). Rota nova DELETE /v1/dispositivos/atual/push?dispositivo_id= (idempotente, só apaga se o aparelho for do usuário logado)

## O que preciso / o que mudou
Chamar a rota no logout do shell, antes de descartar o access token (best-effort, sem bloquear a saída), e ajustar o comentário de apps/mobile/src/lib/push.ts:69

## Pronto quando
Logout do app apaga o token no servidor
