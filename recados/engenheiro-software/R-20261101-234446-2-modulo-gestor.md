# Declarar @macuxi/promotor no package.json do Gestor (lockfile)

## Contexto
Contexto: na T-0046 (PR https://github.com/aloirr/macuxifdv/pull/33) o Gestor passou a validar promotor.*@1 com EVENTOS_PROMOTOR de modules/promotor/contracts. Como declarar a dependência exige mexer no pnpm-lock.yaml (que é seu), o import ficou relativo ('../../promotor/contracts'), dentro da fronteira (dependency-cruiser OK).
