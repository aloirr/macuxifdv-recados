# 0041 pronta: nomes exatos de perfil, perfil_permissao e usuario_perfil para a escrita e a página Perfis de acesso

## Contexto
Contexto: db/migrations/0041_plataforma_perfis_de_acesso.up.sql (em cima da 0040, mesmo lote), ADR 0033, dicionário docs/banco/plataforma.md seção 'Perfis de acesso'. Drizzle: perfil, perfilPermissao, usuarioPerfil em db/esquema/plataforma.ts; ids idPerfilFabrica(tenant, base) e idUsuarioPerfil(tenant, usuario, perfil) em @macuxi/db.

## O que preciso / o que mudou
Para o Core gravar: (1) plataforma.perfil (codigo ^[a-z][a-z0-9_]{1,39}$ único no tenant entre TODOS, apagados inclusive — perfil_codigo_uk; nome até 80; descricao até 500; base = um dos 7 PERFIS; fabrica; ativo). codigo/base/fabrica imutáveis (23514 perfil_imutavel); os 7 de fábrica já existem em todo tenant (semeados; tenant novo por gatilho) e não desativam nem apagam; app sem DELETE (soft delete). (2) plataforma.perfil_permissao (perfil_id, chave ACAO_RE, concedida, nivel NIVEIS_ESCOPO∪NIVEIS_ALCADA, alvos text[] códigos ou '*'): vazia = fábrica; restaurar = apagar a linha; única viva perfil_permissao_uk (tenant, perfil, chave) — use on conflict ... where deleted_at is null ou update; revogada sem nivel/alvos. Travas 23514 no banco: perfil_permissao_trava_bko / _portal (RN-CORE-33), _pedido (RN-PRO-01), perfil_permissao_escopo_da_base (RN-CORE-04). (3) plataforma.usuario_perfil (usuario_id, perfil_id; única viva usuario_perfil_uk). Gravar com on conflict do nothing: o gatilho usuario_perfil_principal já liga o perfil de fábrica de core.usuario.perfil (o principal, que continua e vai no token); trocar core.usuario.perfil de quem só tem o vínculo de fábrica anterior substitui o vínculo. No COMMIT (23514, constraint no erro): usuario_sem_perfil, usuario_perfil_indisponivel (vínculo com perfil inativo), usuario_perfil_principal (nenhum perfil com a base do principal), perfil_em_uso (desativar perfil com usuário), perfil_fabrica_presente, tenant_ultimo_admin (RN-CORE-35: sempre um usuário ativo com perfil base admin, sem perfil que feche o BKO, com acesso.bko e a gestão pela união). Mensagem antecipada: plataforma.usuario_admin_com_gestao(tenant, usuario) e plataforma.tenant_tem_admin_com_gestao(tenant) (EXECUTE ao macuxi_app). A autogestão (o ator não tira a gestão de si) é do domain do Core. perfil_modulo.perfil agora é o CÓDIGO do perfil (FK perfil_modulo_perfil_fk). Contagem de usuários por perfil: índice usuario_perfil_perfil_ix. Auditoria: plataforma.auditoria, por vocês.
