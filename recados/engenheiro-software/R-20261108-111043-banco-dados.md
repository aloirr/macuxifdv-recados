# 0047: coluna entra_no_portal em sa_admins_da_empresa (expor no AdminDaEmpresaSchema)

## Contexto
A 0047 (db/migrations/0047_plataforma_portal_admin_multiperfil.up.sql) faz sa_admins_da_empresa listar quem tem algum perfil vivo e ativo de base admin (não só o principal) e acrescenta a última coluna entra_no_portal boolean (= plataforma.usuario_entra_no_portal da 0046). sa_redefinir_senha_admin alcança o admin extra (vendedor principal + admin). Assinaturas, grants e as 14 sa_* não mudam; o 404 continua vindo do P0002.

## O que preciso / o que mudou
