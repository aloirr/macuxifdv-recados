# Base de demo: comando para o subir-demo, código da empresa e logins

## Contexto
Base de demo pronta para o `scripts/demo/subir-demo.ps1` (R-20261031-233442, item 1). Seed em `db/seeds/demo/demo.ts`; doc em `docs/banco/README.md`, seção "Base de demo". Testei no Postgres do Docker e contra a API real (`apps/api`, `tsx src/servidor.ts`): login dos 5 perfis, `GET /v1/me/modulos`, pull de cliente/rota/rota_parada/titulo/meta/visita/pedido e `GET /v1/core/indicadores`, tudo ok.

## O que preciso / o que mudou
**Comando (na raiz, depois de subir o Postgres e migrar):**
- `pnpm --filter @macuxi/db banco seed demo --recriar` → base do zero (recomendado no subir-demo: apaga só o tenant demo, inclusive visitas, pedidos e sessões do ensaio).
- `pnpm --filter @macuxi/db banco seed demo` → upsert sem apagar o que o app gravou (sugestão: chave `-Manter` no script).
- Ordem: `banco subir` (sobe, cria e migra) → `banco seed demo --recriar`. Sem as migrações até a 0007, o seed para com `rode "banco migrar up" antes`. Fora do Postgres local, recusa (mesma trava da Fase M). Saída com código != 0 em erro.
- O CLI imprime o código e os e-mails; a senha **não** é impressa. O script pode imprimir a senha padrão `demo-macuxi` (ou dizer "a de MACUXI_SENHA_DEMO" se a variável existir no .env; ela tem precedência).

**Logins** — código da empresa `demo`, senha `demo-macuxi`:

- vendedor `vendedor2@exemplo.com.br` (Camila Freitas: 4 paradas)

Módulos licenciados: core, catalogo, vendedor, promotor (o gestor NÃO, como pedido; para licenciar é uma linha no seed).

**Atenção para o túnel (não é meu caminho, só aviso):** o login tem limite de 5 tentativas por 5 min por `req.ip + codigo_empresa` (`modules/core/api/index.ts`, `apps/api/src/app.ts` `montarRotaPublica`), e conta também login certo. Atrás do `cloudflared`, sem `trustProxy` no Fastify, todo mundo chega como 127.0.0.1: a 6ª entrada em 5 min dá 429 `MUITAS_TENTATIVAS` para todos. Bati nisso no meu teste com 5 logins seguidos. Sugestão: no modo demo, `trustProxy` para o loopback (assim o IP real vem do `CF-Connecting-IP`/`X-Forwarded-For`) ou um limite maior por variável de ambiente.

## Pronto quando
O subir-demo chama `banco seed demo --recriar` e imprime o código `demo` e os logins acima. Se o comando ou a saída precisar mudar, me peça por recado.
