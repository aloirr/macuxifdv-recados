# A9 (restauração do dump, ADR 0024 item 9): postgresql-client-16 no alvo teste-db do apps/api/Dockerfile

## Contexto
T-0075, 3ª execução do DBaaS. O gerente pediu o item 9 da ADR 0024 ("teste de restauração") como item complementar **A9** do `db/dbaas/teste-compatibilidade.ts`. O A9 faz `pg_dump -Fc --enable-row-security` da base de teste já migrada e com seed, restaura numa 2ª base de teste (`<base>_r`) com `pg_restore -L` e compara contagens, RLS, políticas e o resto do catálogo.

A imagem `macuxi-api-teste:<sha>` (alvo `teste-db` do `apps/api/Dockerfile`) vem da `node:24-bookworm-slim`, que **não tem pg_dump nem pg_restore**. O `postgresql-client` do Debian bookworm é o 15, e o pg_dump 15 recusa servidor 16. Sem os binários, o A9 sai ❌ como complementar (não muda o código de saída) e registra a proposta abaixo.

## O que preciso
No alvo **`teste-db`** (só nele, nunca na `final`), instale o `postgresql-client-16` do repositório PGDG. Exemplo, depois do `USER root` que já existe:

```dockerfile
RUN apt-get update && apt-get install -y --no-install-recommends ca-certificates curl && \
    install -d /usr/share/postgresql-common/pgdg && \
    curl -fsSo /usr/share/postgresql-common/pgdg/apt.postgresql.org.asc https://www.postgresql.org/media/keys/ACCC4CF8.asc && \
    echo "deb [signed-by=/usr/share/postgresql-common/pgdg/apt.postgresql.org.asc] https://apt.postgresql.org/pub/repos/apt bookworm-pgdg main" > /etc/apt/sources.list.d/pgdg.list && \
    apt-get update && apt-get install -y --no-install-recommends postgresql-client-16 && \
    rm -rf /var/lib/apt/lists/* && pg_dump --version
```

- O script acha o binário no PATH, em `/usr/lib/postgresql/16/bin` ou na pasta de `DBAAS_PG_BIN`. O `.sh` já repassa essa variável ao contêiner.
- Não precisa mudar nada no `dbaas-teste.yml`. O download do PGDG acontece no build, no runner do GitHub; a VM continua só com o GHCR.

## Pronto quando
A `macuxi-api-teste:<sha>` responder `pg_dump --version` e `pg_restore --version` com 16.x. Se preferir não mexer na imagem, me responda, e o A9 fica registrado como "não rodou" com esta proposta na ADR.
