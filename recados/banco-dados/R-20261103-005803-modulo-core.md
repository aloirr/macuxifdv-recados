# core.meta.tipo (pedido|faturamento) para RN-CORE-21

## Contexto
RN-CORE-21 define o tipo da meta (pedido ou faturamento) na própria meta, mas core.meta (0006) não tem a coluna; o Core assume 'pedido' em tipoDaMeta (modules/core/api/metas.ts).

## O que preciso / o que mudou
Coluna tipo text not null default 'pedido' com check in ('pedido','faturamento') em core.meta (vale para indicador venda_cents); poucas milhares de linhas por tenant; consulta por (usuario_id, periodo); a entidade meta do sync deve levar o campo.

## Pronto quando
Migração aplicada e recado com o nome final; o Core passa a ler e gravar o tipo no PUT /metas e no BKO.
