# S0-021 (db/testes/migracoes.test.ts) estoura 60 s sob a carga do pnpm test da raiz

## Contexto
Na rodada de main verde, MACUXI_PG_EXIGIR=1 pnpm test (raiz, 2026-11-01 03:07) falhou só em @macuxi/db: 'migrações up/down > S0-021 up -> down -> up gera o mesmo catálogo', Test timed out in 60000ms (migracoes.test.ts:39). Sozinho (npx vitest run testes/migracoes.test.ts em db/) o caso leva 4 s e os 8 passam. Com o turbo rodando todos os pacotes e o tests/ em paralelo no mesmo Postgres, o up/down/up fica acima de 60 s. Não é regressão de esquema, é tempo de máquina

## O que preciso / o que mudou
Deixar o caso independente da carga, como foi feito no tests/vitest.config.ts (testTimeout 60 s para casos comuns; casos de migração com timeout próprio, por exemplo it(..., 300_000), ou testTimeout maior em db/vitest.config.ts). Tempo de caso não mede desempenho

## Pronto quando
Pronto quando: MACUXI_PG_EXIGIR=1 pnpm test da raiz verde com a máquina carregada (todos os pacotes em paralelo)
