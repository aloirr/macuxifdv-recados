# Código FDV para TODOS (5 dígitos, sequencial, automático); usuário nunca é excluído; vínculo ERP pelo Vincular e automático por nome completo; documentar na API e no Conector

## Mensagem do dono do produto (chat, 15/11/2026 ~11h de Manaus)
> "1 aprovado
> 2 todos tem codigo fdv que é gerado ao criar o usuario. É automático e é o codigo padrao do macuxi para todos os usuarios. O formato dele sao de 5 digitos, em ordem sequencial. Usuarios nunca podem ser excluidos, apenas inativados. No caso do codigo erp, o integrador puxa os usuarios e os dados deles pelo codigo erp e o bko vincula ao usuario do maxima clicando em vincular. Na integracao, o macuxi verifica o nome completo do usuario erp x usuário maxima, se forem igual, vincula automático. Lembre de por essas regras e as outras na documentação da API e conector."

As perguntas da ponte:
1. Aprova as 5 telas do Código FDV e do Vincular (`recados/anexos/R-20261115-erp-vinculo-codigo-fdv/`)?
2. Código FDV só para vendedor e promotor, ou para todos os perfis?

"usuário maxima" = usuário do **Macuxi** (leitura da ponte; é o usuário do FDV).

## O que fica decidido
1. **Telas do Código FDV e do "Vincular vendedor do ERP": APROVADAS**, com os ajustes abaixo.
2. **Código FDV:**
   - **TODOS os usuários** têm, em todos os perfis;
   - é **gerado automaticamente ao criar o usuário**;
   - é o **código padrão do Macuxi** para o usuário;
   - **formato: 5 dígitos, sequencial** (ex.: 00001, 00002…), por empresa, nunca reaproveitado. Substitui o "FDV-0001" da proposta;
   - aparece só para leitura, com botão de copiar, no cadastro e na coluna da lista;
   - usuários que já existem recebem o código na migração, na ordem de criação.
3. **Usuário NUNCA é excluído, só inativado.** Isso vale para o BKO, o portal, a API e a carga.
4. **Código ERP e vínculo:**
   - o integrador (Conector ou API) traz os usuários e os dados deles **pelo código ERP**;
   - no BKO, o admin liga o usuário do ERP ao usuário do Macuxi pelo botão **"Vincular"** (telas aprovadas);
   - **vínculo automático na integração:** se o **nome completo** do usuário do ERP for **igual** ao nome completo de um usuário do Macuxi, o Macuxi vincula sozinho.
   - **Pontos para o time propor antes do PR** (sem mudar a regra):
     - normalização da comparação: maiúsculas, acentos e espaços duplos;
     - o que fazer quando 2 ou mais usuários do Macuxi tiverem o mesmo nome. Sugestão da ponte: não vincular sozinho e avisar o admin para usar o Vincular;
     - não vincular automático a usuário que já tem outro código ERP.
5. **Documentação:** estas regras e as outras decididas hoje entram na **documentação da API (Hub /integracao/v1) e do Conector**, e no ROTEIRO do kit:
   - filial de cadastro e de venda;
   - vendedor sem filial bloqueado;
   - marca e referência com código e nome no produto;
   - a carga cria e atualiza a marca concorrente pelo código;
   - estoque carregado uma vez por dia e sincronização completa;
   - Código FDV e vínculo pelo código ERP ou pelo nome completo;
   - usuário nunca excluído.
