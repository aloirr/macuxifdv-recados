# BKO: parâmetro dos campos obrigatórios do pré-cadastro

Texto literal do Alexandre (chat com o Agente PO, 23/11/2026 10h29 de Manaus):

> No força de venda, é importante o BKO ter uma tela lá em parâmetros onde ele define quais campos são obrigatórios no pré-cadastro.

## O que fica decidido
1. Entra na v1.0.28: tela no BKO, em Parâmetros, onde a empresa escolhe quais campos do pré-cadastro de cliente são obrigatórios.
2. O formulário do pré-cadastro no app Campo segue esse parâmetro (offline, com o parâmetro sincronizado) e a API revalida.
3. O gerente define com o designer-ux os campos que são sempre obrigatórios (ex.: CNPJ/CPF e nome) e os configuráveis, e manda a previsão atualizada.
