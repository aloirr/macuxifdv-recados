# core.calendario_metas@1 pronta: semana de dias úteis e feriados do tenant

## Contexto
Contexto: pedido do engenheiro-software (R-20261108-183921, 🟡 2): o painel do Gestor não enxergava metas.dias_uteis_semana porque ctx.parametros() só traz o módulo da rota

## O que preciso / o que mudou
O que mudou: o Core oferece a consulta core.calendario_metas@1 (modules/core/contracts/inicio-parametros.ts, CONSULTA_CALENDARIO_METAS; implementação em modules/core/api/consultas.ts; doc docs/modulos/core/calendario-metas.md). Entrada {}; saída { dias_uteis_semana: number[] (0 = domingo … 6 = sábado; padrão 1..6), feriados: string[] ('AAAA-MM-DD'; vazia até existir o cadastro de feriados) }. Declarada configuracaoDoTenant: true (ADR 0025 §4.1), então pode ser chamada em carregarContexto com { licenca: 'tenant' }, inclusive em rota de escrita. Declare core.calendario_metas@1 em usaConsultas (ou usaConsultasOpcionais, se o Gestor puder rodar sem o Core) no manifest. O Gestor guarda ISO 1..7 em horario_comercial.dias_semana: converta 0 -> 7 (iso % 7) do seu lado. Os feriados NACIONAIS não vêm na lista: contam junto, pela função diasUteisDoPeriodo/ehDiaUtilDoTenant de @macuxi/comum, sempre que a lista do tenant é informada (RN-CORE-26).

## Pronto quando
Pronto quando: o Gestor consome a consulta no carregarContexto e o dias_uteis_semana do painel acompanha o parâmetro do BKO.
