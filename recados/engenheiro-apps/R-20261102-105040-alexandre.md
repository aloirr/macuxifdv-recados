# Decisão — frete: CIF quando a empresa paga, FOB quando o cliente paga, com transportadora obrigatória

## Contexto
Decisão do Alexandre sobre o frete, depois da avaliação fiscal no Cowork. **Substitui a RN-VEN-16 e a parte de frete da spec R-20261102-093007-alexandre.** O resto da spec continua valendo. A seção 4 da spec (dados e integração) se ajusta como abaixo.

## O que preciso / o que mudou
**Regra simplificada: quem paga o frete define a modalidade.**

Texto para `docs/produto/03-regras-de-negocio.md`:
> - **RN-VEN-16 Frete** Modalidade obrigatória no pedido, padrão **CIF** (parâmetro do tenant `frete_modalidade_padrao`).
>   - **CIF** = a empresa que vende paga o frete. O frete está incluso no preço: o pedido não tem valor de frete nem pede transportadora.
>   - **FOB** = o cliente paga o frete. **Transportadora obrigatória**, preenchida pelo vendedor: escolhida da lista cadastrada no BKO ou, se não estiver na lista, digitada (nome e CNPJ obrigatórios; telefone opcional). A transportadora digitada fica só no pedido; o BKO vê a lista das digitadas para cadastrar. O valor do frete não entra no pedido (o cliente paga direto à transportadora).
>   - O frete nunca entra no desconto efetivo (RN-VEN-03) nem no realizado da meta (RN-CORE-21).

**Tela (aba Itens, card Condições, logo abaixo do desconto do pedido):**
```
Frete
[ CIF ✓ ]  [ FOB ]
CIF: frete por conta da empresa, incluso no preço.
```
Com FOB selecionado:
```
Frete
[ CIF ]  [ FOB ✓ ]
FOB: frete por conta do cliente.
Transportadora *  [ Rápido Norte Transportes ▾ ]   + Digitar transportadora
```
"Enviar pedido" fica bloqueado com FOB sem transportadora: "Informe a transportadora do frete FOB." Funciona offline (a lista de transportadoras vem no pull).

**Integração (pedido devolvido ao ERP, RN-INT-08):**
```json
"frete": { "modalidade": "CIF" }
"frete": { "modalidade": "FOB", "transportadora": { "tipo": "cadastrada", "id": "…" } }
"frete": { "modalidade": "FOB", "transportadora": { "tipo": "digitada", "nome": "…", "cnpj": "…", "telefone": "…" } }
```
O mapeamento para a NF-e é do ERP (orientação ao cliente na doc 06): CIF → modFrete 0 (transportadora contratada pela empresa) ou 3 (frota própria); FOB → modFrete 1, com o grupo da transportadora preenchido com os dados enviados.

**PDF e BKO:** "Frete: CIF – por conta da empresa" ou "Frete: FOB – por conta do cliente · <transportadora> (CNPJ)".

**Sai da spec anterior:** valor de frete em R$ ou % e a opção "Cliente irá definir a transportadora".
