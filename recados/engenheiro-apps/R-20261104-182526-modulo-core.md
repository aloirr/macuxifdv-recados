# Formato final dos dados do Início (useInicio): campos aditivos do @1 prontos

Todos os campos abaixo são ADITIVOS e OPCIONAIS em `VisaoInicioSchema` (core.inicio@1; modules/core/contracts/inicio.ts), preenchidos por `montarInicio` (modules/core/app/lib/inicio-local.ts) e entregues por `useInicio()`. Dinheiro em centavos; percentuais em pontos-base (10000 = 100%).

- `saudacao`: 'Bom dia' | 'Boa tarde' | 'Boa noite' (fuso do tenant; 5h-11h59 / 12h-17h59 / resto). Use com o nome do usuário da sessão.
- "N visitas hoje · M feitas": já existe em `rota.paradas_hoje` e `rota.visitadas_hoje` (null no escopo equipe).
- `recados_hoje`: `{ novos: number, itens: [{ id, titulo, subtitulo (corpo), tipo, criada_em, hora ("HH:mm" no fuso), lida, link, destaque }] }` (máx. 3; o recado do dia da T-0073 vem primeiro, com `destaque: true`; `novos` = não lidas da caixa). "Ver todos" = rota `/m/core/notificacoes` (central existente).
- `meta_hoje`: `{ indicador, situacao, realizado_hoje, meta_dia, faltam_hoje, mes_pct } | null`. Meta de venda; sem ela (promotor) a primeira meta que o usuário tem. null = sem meta OU venda ainda sem cópia (nesse caso veja `sem_realizado`). `faltam_hoje` = max(0, meta_dia - realizado_hoje); null em dia não útil; 0 com o mês batido. `mes_pct` = (realizado até ontem + hoje) / meta do mês.
- `sem_realizado`: indicadores ('venda_cents' | 'positivacao') com meta no mês e sem realizado na cópia (use para "Sincronize para ver as vendas").
- `sincronizacao`: `{ ultima_em: ISO UTC | null, hora: "HH:mm" no fuso | null, fila: number }` ("Última sincronização 16:25 · 0 na fila"; RN-CORE-23). `fila` = itens pendentes no motor.
- `equipe_nome: string | null` (nome da equipe, vem na cópia core.inicio@1; preenchido pela API v1 em calcularInicio).
- `equipe_agora[].cliente_nome: string | null` (só em 'em_visita').
- `useNotificacoes()` exportado por `@macuxi/core/app`: `{ caixa, naoLidas, marcarLida(id), carregado }`. Para tocar num recado do Início: `await marcarLida(item.id)` e navegue pelo `link`.
- Os campos antigos (`notificacoes`, `metas`, `rota`, `recado`) continuam iguais.
