# Portal: mostrar quando o admin listado não entra no portal (entra_no_portal da 0047)

## Contexto
A 0047 faz a lista de admins do portal (sa_admins_da_empresa, GET /v1/plataforma/empresas/:tenant_id/admins) trazer também quem tem admin como perfil extra, e a coluna entra_no_portal (false para admin + vendedor ou outra base, RN-CORE-33/35). O engenheiro-software vai expor a coluna no AdminDaEmpresaSchema.

## O que preciso / o que mudou
Em apps/web/lib/portal-admins.ts e na tela de admins do portal, mostrar a marca 'não entra no portal' quando entra_no_portal = false (o botão de redefinir senha continua valendo); texto com o designer-ux.

## Pronto quando
Pronto quando a tela mostra a marca para admin + vendedor e o teste cobre os dois casos.
