# Equipe por CSV: rotas para o cartão do portal e tela pública de aceitar convite (/convite/<token>)

## Contexto
T-0087 fatia E (RN-CORE-31): a API da Equipe por CSV e do convite de 1º acesso está pronta no Core (domain, contratos Zod, rotas, testes). Desenho e diferenças: docs/modulos/core/equipe-csv.md ("Como ficou"). Contratos: modules/core/contracts/equipe-importacao.ts (importar `@macuxi/core/contracts`). Todas as rotas do admin aceitam o super-admin com `x-macuxi-tenant`.

## O que preciso
1) Cartão **Equipe** do portal (trocar o "em breve") e a tela Usuários do BKO, com este fluxo (mesmo padrão de conferir/gravar da carga por arquivo):
- `GET /v1/core/equipe/modelo.csv` -> "Baixar modelo (.csv)".
- `POST /v1/core/equipe/importacoes` corpo `{ csv, modo: 'conferir'|'gravar', origem? }` (até 5.000 linhas / 2 MB; passe `origem = window.location.origin` do BKO para vir o link completo). Resposta: `gravado`, `resumo {total,novos,atualizados,sem_mudanca,com_erro}`, `erros[] {linha,coluna,mensagem}`, `avisos[]`, `plano[]` (ordem gerentes -> supervisores -> campo), `erros_csv` (texto pronto para "Baixar erros (.csv)"), e só no `gravar`: `convites[] {usuario_id,nome,email,perfil,caminho,link,expira_em}` e `convites_csv` (para "Baixar convites (.csv)"). `gravar` com erro não grava nada (`gravado:false`). Os links aparecem UMA vez: mostre/baixe na hora e avise isso na tela.
- `GET /v1/core/equipe/convites` -> pendentes (sem link) {usuario_id,nome,email,perfil,expira_em,vencido}; `POST /v1/core/equipe/convites/:usuario_id/renovar` corpo `{ origem? }` -> `ConviteEmitido` (novo link, o anterior deixa de valer).
2) Tela pública de **aceitar convite**: rota do BKO `/convite/<token>` (o `caminho` que a API devolve; sem login). Campos: senha + confirmar (política: 8+ caracteres, letras e números, diferente do e-mail). Chama `POST /v1/auth/convite/aceitar` `{ token, senha }` (rota pública, sem token de sessão) -> `{ codigo_empresa, email, nome }`; depois leve para o login normal já com código da empresa e e-mail preenchidos. 410 `CONVITE_INVALIDO` = "convite usado ou vencido, peça outro ao administrador"; 422 `CONVITE_SENHA_FRACA` = mostrar a mensagem. Não registre o token em log nem em analytics. No app Campo/Gestão não há tela de convite: o aceite é no BKO (navegador do celular serve).
Textos de erro já vêm em português na `mensagem`.

## Pronto quando
Portal grava a Equipe por CSV e baixa o CSV de convites; a pessoa abre o link, cria a senha e entra pelo login. Dúvida de contrato: responda neste recado.
