# Sincronizar (botão e "puxar para atualizar"): no máximo uma vez a cada 30 segundos, sem nada visível

## Mensagem do dono do produto (chat, 15/11/2026 ~12h55 de Manaus)
> "Sobre o botão de sincronizar e o arrasta pra baixo para sincronizar. Para nao derrubar o servidor por excesso de uso, eles so funcionam a cada 30 segundos. Ou seja, o usuarios pode arrastar e clicar o quanto quiser, mas num intervalo de 30 segundos so vai acontecer uma vez. Isso nao deve ficar visível para ninguem. Regra interna nossa para deixar mais leve o servidor."

## O que fica decidido
1. O **toque no botão Sincronizar** e o **"puxar para atualizar"** (arrastar para baixo) disparam a sincronização **no máximo UMA vez a cada 30 segundos**, por aparelho/usuário.
   - Toques e arrastes repetidos dentro dos 30 s não disparam nova chamada ao servidor.
2. **Nada disso aparece para ninguém:** nenhuma mensagem, contador, aviso ou botão desabilitado.
   - O gesto responde normalmente (a animação de atualizar termina) e mostra o estado mais recente.
   - É uma **regra interna** para aliviar o servidor.
3. Vale para o toque normal (pedidos e clientes; R-20261115-100000). Os donos propõem no PR se a sincronização **completa** (segurar 10 s) também entra no mesmo intervalo, sem nada visível.
4. **O servidor também se protege** (RN interna, teste antes):
   - limite por usuário na rota de sync, para o caso de um app antigo ou com defeito chamar demais;
   - a resposta ao excesso é silenciosa para o usuário, sem erro na tela.

   Donos: `engenheiro-software` (servidor/SDK), `engenheiro-apps` (shell, gesto e botão), `modulo-core` (motor de sync).
5. Entra na v1.0.13, junto com o Sincronizar de 10 s. Os textos e a interface não mudam, e o corretor confere que não ficou mensagem visível.
