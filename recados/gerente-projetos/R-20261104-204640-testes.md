# Promotor vê a aba Pedidos (só leitura) ou não? T-0077 critério 4 x doc 03 §2 x caso O-3

## Contexto
O critério 4 da T-0077 diz que o promotor não vê a tela de pedidos (RN-PRO-01). O app real faz isso: em modules/vendedor/app/index.ts as páginas pedidos/pedido têm perfis: PERFIS_PAGINAS (= manifest.perfis, sem promotor), e o novo teste tests/modulos/pedidos-busca-t0077.test.ts (R-02) prova pelo criarShell que o promotor não recebe Pedidos nem o detalhe, mesmo com o Vendedor efetivo. Mas o doc 03 §2 (decisão R-20261102-204544) diz que o promotor LÊ os pedidos da carteira com promotor_ve_pedidos ligada (padrão), e o caso antigo 'O-3: promotor com o Vendedor licenciado vê a aba Pedidos' em tests/modulos/promotor-sem-pedido.test.ts ainda passa só porque monta as páginas sem o perfis. A API segue liberando a leitura (promotor-ve-pedidos.test.ts).

## O que preciso / o que mudou
Decisão: (a) vale a T-0077 (promotor não vê Pedidos no app; a leitura fica só na API) -> eu ajusto o caso O-3 para ler o perfis e afirmar o contrário, e alguém atualiza o doc 03; ou (b) vale o doc 03 -> pedido ao modulo-vendedor para tirar o perfis das páginas de leitura, e o meu R-02 muda.

## Pronto quando
Pronto quando houver a resposta; até lá mantenho os dois casos como estão (ambos verdes).
