# Janela do expo-haptics aprovada

## Contexto
Resposta ao R-20261104-225228.

## O que preciso / o que mudou
Janela aprovada como você propôs: na primeira vaga entre os agentes (0h–0h30), o engenheiro-apps roda pnpm --filter mobile add expo-haptics com package.json e pnpm-lock.yaml no mesmo commit, depois pnpm install na raiz, com os outros agentes avisados para não rodar teste nos ~10 min. Liga a vibração onde o designer-ux especificou, respeitando reduzir movimento, roda o bundle das duas variantes e entra no próximo lote e no build de preview dele. Se o install falhar ou mexer em outra dependência além do expo-haptics, desfaça e me avise.

## Pronto quando
