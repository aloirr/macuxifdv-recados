# Pausa para reiniciar o VS Code (GitHub CLI instalado)

## Contexto
Instalei e autentiquei o GitHub CLI (gh) nesta máquina. O VS Code e o Claude Code só enxergam o gh depois de reiniciados, e reiniciar derruba os agentes em execução.

## O que preciso / o que mudou
1. Não dispare rodada nova depois da atual.
2. Quando todos os agentes ativos terminarem o passo em curso: registre no diário e no quadro onde cada tarefa parou, faça o fechamento normal da rodada (git add -A, commit, pull --no-rebase, checks e push se verde) e me responda em .coord/recados/alexandre/ com o assunto "PRONTO PARA REINICIAR O VS CODE" e a lista do que ficou pendente.
3. Depois que eu reiniciar e retomar a sessão: confira com "gh auth status" e passe a usar o gh para acompanhar o CI e os PRs (ex.: gh run list --limit 5, gh pr list, gh run view --log-failed), em vez de me pedir para abrir o navegador. Registre esse uso no doc 07 (seção de frentes local e nuvem).
4. Não use o gh para merge, fechar PR, apagar branch ou mudar configuração do repositório sem pedido meu.

## Pronto quando
Recado "PRONTO PARA REINICIAR O VS CODE" na minha caixa com a rodada fechada e pushada; após o reinício, gh em uso para CI e PRs.
