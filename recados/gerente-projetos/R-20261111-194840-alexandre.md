# Modelo de integração definido: API nos dois sentidos, 5 modelos de ERP, carga só pelo Hub, arquivo só interno, retorno completo, implantação de 30 dias

## Contexto
Respostas do Alexandre (11/11/2026, ~19h50 de Manaus) às 8 perguntas sobre o modelo de integração. Texto literal: "1 letra c / 2 totvs, winthor e pegue os 3 maiores do mercado brasileiro / 3 ok / 4 os dois / 5 so para o time interno para empresas sem erp / 6 1 a 2 minutos ok / 7 tudo / 8 cobrado a parte prazo 30 dias". Integração é a parte crítica do negócio: é o maior gargalo das empresas e define o sucesso do produto. Completa o R-20261111-191644-alexandre (T-0163 e T-0164 do R-20261111-184524-gerente-projetos).

## O que preciso
Decisões (entram na esteira depois do BUILD PRONTO da v1.0.4):
1. **Opção API = os dois sentidos:** (a) o ERP do cliente envia para a nossa API (Hub público, documentado em OpenAPI, credencial por empresa) e (b) o Macuxi busca na API do ERP em nuvem (adaptadores nuvem-a-nuvem). No cadastro da empresa no config.: CONECTOR ou API (e, dentro de API, "o ERP envia" ou "o Macuxi busca").
2. **Modelos prontos por ERP**, nesta ordem: TOTVS Protheus, TOTVS WinThor, SAP Business One, Sankhya e Senior. Cada modelo traz as views vw_macuxi_* e a entrada de pedidos prontas para o banco daquele ERP, ou o adaptador da API dele quando o ERP for em nuvem (ex.: SAP B1 em HANA pela Service Layer). Objetivo: instalar o Conector sem técnico escrevendo SQL.
3. **Carga inicial pelo time interno: SEMPRE pelo Hub**, a partir de um banco de implantação, com a mesma validação, idempotência, trilha e evento para os apps. Proibido SQL direto nas tabelas da produção.
4. **Instalação do Conector pelos dois caminhos:** assistente no config. para o técnico do cliente e acesso remoto do time de implantação.
5. **Carga por arquivo só para o time interno e só para empresa sem ERP.** Não aparece para o cliente. Isso destrava a T-0164 (Excel nativo) com este escopo.
6. **Pedido até o ERP em 1 a 2 minutos**, como hoje.
7. **Retorno do ERP no piloto: tudo** — número do pedido, status, nota fiscal, faturamento, títulos/financeiro e estoque com atualização quase em tempo real (definam a frequência possível sem pesar no ERP).
8. **Implantação é serviço cobrado à parte, com prazo de 30 dias.** O desenho deve prever o acompanhamento da implantação por empresa no config. (etapas, responsável, data prometida e situação), para o time cumprir o prazo.

## Pronto quando
Desenho único da integração (engenheiro-software, modulo-integracao e banco-dados), ADR quando mudar contrato ou regra, tarefas no quadro com ordem e prazo, e o meu ok antes de codar.
