# Decisão O-3: o promotor pode ver os pedidos da carteira, mas isso é desativável na configuração do perfil Promotor (padrão: ligado)

## Contexto
A sessão da nuvem da T-0061 Vendedor apontou o conflito entre a O-3 do doc 03 (promotor lê os pedidos da carteira) e o critério "o promotor nunca vê o pedido". Decido assim:

## O que preciso / o que mudou
1. **Regra:** o promotor **pode ver** (somente leitura) os pedidos dos clientes da própria carteira. A RN-PRO-01 continua: ele nunca cria, edita, cancela, duplica, exclui nem aprova pedido (UI e API, 403).
2. **Desativável:** a leitura é uma opção da **configuração do perfil de acesso Promotor**, por tenant, editada pelo admin no BKO, com auditoria (RN-AUD-01). Nome sugerido: `promotor_ve_pedidos`, **padrão: ligado**. Desligada, a API devolve 403 nas rotas de lista, detalhe e pull de pedidos para o perfil promotor, e o app não mostra pedido em nenhum lugar (Cliente 360 inclusive). Checada a cada requisição, como a licença (RN-CORE-01).
3. **Quem faz (sem duplicar):**
   - **modulo-core (nuvem, PR próprio):** a opção na configuração do perfil Promotor (contrato, parâmetro do tenant, tela do BKO para o admin, auditoria) e a consulta pública que diz se ela está ligada;
   - **modulo-vendedor (nuvem, no PR da T-0061):** a API de pedidos respeita a opção para o perfil promotor; teste com a opção ligada (lê a carteira, nunca escreve) e desligada (403);
   - **testes:** incluir os dois casos no e2e de permissões.
4. **gerente:** atualize o doc 03 — matriz de permissões ("Ver pedidos" do Promotor = "carteira (leitura), desativável no perfil"), a O-3 e a tabela de parâmetros (`promotor_ve_pedidos` = sim) — e corrija o critério da T-0061 ("o promotor nunca cria nem altera pedido; a leitura segue a opção do perfil").
5. Entra no build da meia-noite se fechar até 23h; se não, a leitura fica ligada (comportamento de hoje) e a opção entra no build final.

## Pronto quando
Doc 03 e T-0061 atualizados; opção no perfil Promotor no BKO; API de pedidos respeitando a opção, com testes nos dois estados.
