# Bug — Login: campo Senha sem o botão de olho para mostrar a senha

## Contexto
Teste de campo do Alexandre no APK de preview do Macuxi Campo (demonstração, T-0026). Tela Entrar (`login.tela`), antes do login, online. Componente compartilhado: o Macuxi Gestão tem o mesmo problema.

**Passos**
1. Abrir o APK de preview do Macuxi Campo.
2. Na tela Entrar, tocar no campo Senha e digitar.

**Esperado:** um ícone de olho no campo Senha para mostrar e ocultar o que foi digitado.

**Obtido:** a senha fica sempre oculta, sem como conferir o que foi digitado.

**Tela:** Entrar, campo Senha (`login.senha`) · **Perfil:** nenhum (antes do login) · **Conexão:** online

## O que preciso / o que mudou
Em `modules/core/app/components/tela-login.tsx` o campo Senha usa `secureTextEntry` fixo. Incluir o botão de olho no campo Senha.

## Pronto quando
- O ícone de olho alterna entre mostrar e ocultar (olho ↔ olho cortado).
- O botão tem `testID="login.senha-mostrar"`, `accessibilityLabel` "Mostrar senha" / "Ocultar senha" e alvo de toque ≥ 48 dp.
- A senha volta a ficar oculta depois de um erro de login (quando o campo é limpo).
- Teste de componente cobre a alternância; funciona no Campo e no Gestão.
- O login da web do BKO foi conferido e recebeu o mesmo ajuste, se faltar.
