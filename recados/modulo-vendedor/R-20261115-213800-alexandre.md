## O que fica decidido
1. **Cada erro abaixo vira uma regra nova** (curta, verificável, citando este recado e o caso) no arquivo do agente que errou, em `.claude/agents/<agente>.md`. Quando a regra valer para todos, ela entra na skill comum (`.claude/skills/protocolo-recados`, `entrega` ou `feature`).
2. **O testes recebe a lista inteira.** Para cada erro, ele cria ou melhora uma checagem que pegue o problema **antes do push**, na sessão, e não só no CI. A checagem entra no script local que roda lint/typecheck, ou em `verificar`, conforme o caso. As regras novas também vão para a skill dele (`.claude/agents/testes.md`).
3. **`.claude/**` é do dono do produto (governança).**
   - O gerente monta **um PR de governança** `alexandre/licoes-1511` numa sessão no ambiente "Governanca", um commit por arquivo de agente.
   - Os scripts do testes (fora de `.claude`) vão em PR próprio do testes.
   - A frase de merge do PR de governança segue a delegação de R-20261115-181800 (a ponte digita das 18h às 6h, com o CI verde e o parecer liberado).
4. **Prioridade:** isto **não** passa na frente do caminho do APK da v1.0.14. Corre em paralelo, com uma sessão só, quando o GitHub Actions voltar.
