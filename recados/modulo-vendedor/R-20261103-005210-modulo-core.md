# T-0061 Core: opção promotor_ve_pedidos e consulta core.promotor_ve_pedidos@1

## Contexto
Pedido do Alexandre (T-0061, complemento do Core): opção do perfil Promotor para ver pedidos. Por tenant, padrão LIGADO (sem registro = ligado). A opção só controla a LEITURA (RN-PRO-01: a escrita de pedido pelo promotor continua sempre negada, UI e API). Contrato pronto na branch nuvem/T-0061-core-promotor-ve-pedidos.

## Nomes finais
- Consulta: `core.promotor_ve_pedidos@1`, constante `CONSULTA_PROMOTOR_VE_PEDIDOS` em `modules/core/contracts` (promotor-pedidos.ts). Entrada `{}` (strict). Saída `{ ligado: boolean }` para o tenant da requisição. Avaliada no banco a CADA chamada (sem cache, sem valor em JWT/sessão).
- Parâmetro: `plataforma.parametro`, modulo `core`, chave `promotor_ve_pedidos`, valor JSON booleano. Constante `PARAMETRO_PROMOTOR_VE_PEDIDOS`; padrão `PROMOTOR_VE_PEDIDOS_PADRAO = true`.
- Offline: vai no pull da entidade `parametro` do Core (lista fixa: `checkin.raio_m` e `promotor_ve_pedidos`). No app: `promotorVePedidosDasLinhas(await motor.linhas('parametro'))` (exportado de `modules/core/contracts`; sem linha ou linha removida = true).
- Admin edita no BKO do Core: `GET|PUT /v1/core/parametros/promotor-ve-pedidos` (ação `parametro.promotor_ve_pedidos`, só admin, auditada).

## O que preciso do Vendedor (modulo-vendedor)
1. Declarar `usaConsultas: [..., 'core.promotor_ve_pedidos@1']` no manifesto.
2. Na API: leitura de pedido (lista, detalhe, PDF, pull de pedido/pedido_item para o promotor) NEGADA ao perfil promotor quando `ctx.consultar(CONSULTA_PROMOTOR_VE_PEDIDOS, {})` devolver `ligado: false` (403, mensagem em português com a ação seguinte). Escrita continua negada sempre. Vendedor e demais perfis não mudam.
3. No app: esconder a aba/seção de pedidos do promotor quando `promotorVePedidosDasLinhas(...)` for false (offline); o Cliente 360 do Core já filtra o histórico/contagem de pedidos e as seções de extensão de pedidos no ponto de montagem do Core.

## Pronto quando
API do Vendedor nega a leitura de pedido ao promotor com a opção desligada e libera com ela ligada (tenant A desliga, B continua ligado), com teste; app do promotor sem aba/seção de pedidos quando desligada.
