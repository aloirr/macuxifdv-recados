# DEFEITO D-4: etapas da Fase M do Vendedor dão 404 na API real e o Sincronizar do Campo termina com erro

## Contexto
Validação da T-0018 critério 2 ("Sincronizar" do Campo na API real termina sem erro, D-2), testes com Postgres real. DEFEITO D-4: no modo v1 o shell passa ao motor TODAS as `etapasSync` (apps/mobile/src/state/plataforma.tsx:180, `modo === 'demo' ? [etapaMe, ...shell.etapasSync] : shell.etapasSync`). As etapas do Vendedor (modules/vendedor/app/etapas.ts: `alcadas` → GET /me e /discount-policy; `carteira` → /customers; `produtos` → /products; `pedidos` → /orders) são o REST da Fase M, que a API real não tem: 404 `NAO_ENCONTRADO` "Rota não encontrada." e, como não tratam 4xx, a etapa lança e `motor.sincronizar()` termina com `erro` para todo vendedor.
