# 0035 super-admin: conformidade.test.ts precisa aceitar 4 tabelas só por função e 20 SECURITY DEFINER novas

## Contexto
T-0087 fatia P, migração `db/migrations/0035_plataforma_super_admin.up.sql` (ADR 0029, desenho docs/desenho/T-0087.md §6). Quatro tabelas novas de plataforma **sem tenant_id** e **sem política nem grant para o macuxi_app/macuxi_worker** (RLS forçado, só a política `manutencao`; acesso só por funções SECURITY DEFINER): `plataforma.super_admin`, `plataforma.super_admin_desafio`, `plataforma.super_admin_sessao`, `plataforma.auditoria_plataforma` (o tenant fica em `tenant_alvo_id`, sem FK, para sobreviver à `excluir_tenant`).
