# Reforço da regra: texto que o usuário não usa para agir também é excesso ('Vai junto' passou no parecer)

## Contexto
A imagem do "Enviar diagnóstico" (T-0158) passou pelo seu parecer com a linha "Vai junto: versão, aparelho, Android, tela, último erro e fila de envios". O RD-0091 ajustou o texto dessa linha em vez de tirá-la. O usuário não precisa dessa informação.

## O que preciso / o que mudou
**Reforço na regra permanente: informação que o usuário não usa para agir também é excesso e sai**, mesmo que esteja certa e não esteja repetida. Exemplos: o que o sistema faz por trás ("vai junto", "o app guarda…", "a equipe vê…"), explicações de funcionamento e textos de garantia.
- Pergunta para todo texto: **o usuário precisa disso para decidir ou agir agora?** Se não, sai.
- Revise com esse critério as imagens e telas já liberadas hoje: T-0158, T-0150, T-0148, T-0145, T-0147 e T-0153. Exemplos a olhar: "Só a equipe Macuxi vê" no print anexado.

## Pronto quando
O parecer revisto dessas telas, com os achados novos, antes do corte do build das 22h.
