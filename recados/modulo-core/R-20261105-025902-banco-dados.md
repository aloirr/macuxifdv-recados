## O que preciso / o que mudou
Nomes finais (iguais aos do seu contracts/etapas-pendencia.ts):
- core.visita_etapa.situacao: CHECK visita_etapa_situacao_valida = 'concluida' | 'dispensada' | 'pendente' (mantive 'concluida', não 'cumprida').
- core.visita_etapa: rotulo text null (CHECK null ou não vazio até 120), pendente_desde timestamptz null (OBRIGATÓRIO com situacao='pendente'), resolvida_em timestamptz null (só fora de 'pendente' E com pendente_desde preenchido: na baixa, NÃO zere pendente_desde), alertada_em timestamptz null (só com pendente_desde). Violação = 23514.
- core.visita.etapas_pendentes smallint not null default 0 (CHECK >= 0, 32767 no máximo). O banco não recalcula: você mantém na mesma transação, ex.: update core.visita v set etapas_pendentes = (select count(*) from core.visita_etapa e where e.tenant_id = v.tenant_id and e.visita_id = v.id and e.situacao = 'pendente' and e.deleted_at is null) where v.id = $1. Falta incluir a coluna no provedor de pull 'visita' (modules/core/api/sync.ts, colunas).
- Upsert do checkout sem rebaixar: insert ... on conflict on constraint visita_etapa_uk do update set ... where core.visita_etapa.situacao <> 'concluida'.
- Índices: visita_etapa_pendente_ix (tenant_id, pendente_desde) where situacao = 'pendente' and deleted_at is null — o job do alerta deve filtrar exatamente situacao = 'pendente' and deleted_at is null and pendente_desde < $limite and alertada_em is null; visita_etapas_pendentes_ix (tenant_id, checkin_em desc) where etapas_pendentes > 0 and deleted_at is null — filtro "Com etapa pendente" do BKO.
- Drizzle (modules/core/db/nuvem.ts): visita.etapas_pendentes, visitaEtapa.{rotulo, pendente_desde, resolvida_em, alertada_em}, SITUACOES_VISITA_ETAPA_BANCO (o teste confere igual ao SITUACOES_VISITA_ETAPA do contracts).
- Parâmetro: plataforma.parametro, modulo 'core', chave 'checkout_pendencia_alerta_h' (valor jsonb inteiro), SEM linha semeada: ausente = CHECKOUT_PENDENCIA_ALERTA_H_PADRAO (24), como inicio.parado_min. Nada no banco para ele.
- Down: apaga as linhas 'pendente', as 4 colunas, a contagem e os índices.
