## O que mudou (nomes finais)
**catalogo**
- `uso_ia` (fora do sync).
- `debitar_cota_ia(p_usuario_id uuid, p_limite integer, p_agora timestamptz default now()) returns integer`: devolve o total do dia depois do débito. Devolve null quando o limite foi atingido ou quando o limite é <= 0. Dia no fuso do tenant. Atômica (INSERT ... ON CONFLICT ... WHERE consultas < limite).
- `consultas_ia_do_dia(p_usuario_id uuid, p_agora timestamptz default now()) returns integer`.
- Tabelas novas:
  - `catalogo_no`;
  - `produto_no`;
  - `produto_conteudo` (descricao, aplicacoes, argumentos_venda, faq jsonb, campanha, destaque);
  - `produto_atributo` (nome, valor, valor_num, unidade, ordem);
  - `produto_midia`;
  - `sinonimo`;
  - `produto_busca`: documento tsvector preenchido por gatilho. Consulta: `documento @@ websearch_to_tsquery('portuguese', catalogo.sem_acento($1))`;
  - `deposito`;
  - `estoque_saldo`;
  - `busca_log` (fora do sync).
- `tabela_preco_item.unidade`: nulo = unidade base; CX = preço próprio da caixa.

**vendedor**
- `pedido`, colunas novas:
  - orçamento: tipo (pedido|orcamento), orcamento_validade, orcamento_id, convertido_em;
  - preço: acrescimo_pct, desconto_efetivo_pct;
  - frete: frete_modalidade (CIF|FOB). Segue a decisão R-20261102-105040: o pedido não tem valor de frete; FOB exige transportadora cadastrada, ou digitada com nome e CNPJ; CIF fica sem transportadora;
  - transportadora: transportadora_id, transportadora_digitada, transportadora_nome, transportadora_documento, transportadora_telefone;
  - entrega: endereco_entrega_id, endereco_entrega (jsonb);
  - ERP: enviado_erp_em, integrado_em, faturado_em, total_faturado_cents.
  - total_cents não muda com o frete.
- `pedido_item`: fator, quantidade_base (o gatilho grava quantidade × fator), acrescimo_pct, preco_minimo_cents e quantidade_faturada (na UNIDADE BASE, de 0 a quantidade_base).
- Tabelas novas: `transportadora` e `pedido_faturamento` (evento_id único, itens jsonb). `cliente_frete` saiu, porque o padrão do frete agora é só do tenant.
